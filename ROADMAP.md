# CORE — delivery roadmap

This roadmap replaces the historical phase numbering in HANDOFF.md and the prototype UI. Historical phases 0 (synthetic corridor) and 1 (globe implementation) are existing assets, not evidence of production readiness. Deliver one phase at a time; no phase below authorizes an agent to execute infrastructure changes.

| Phase | Scope | Acceptance criteria | Status |
| --- | --- | --- | --- |
| 0 — Foundation & GitHub | Audit, documentation, reproducible build/tests, preserve history, safe GitHub publication | Required docs present; application preserved with documented minimal fixes; build and tests pass; browser evidence or explicit pending status; secret/size review; verified commit on remote main | Foundation delivered; remote commit verification recorded in delivery report |
| 1 — Prototype reliability & data honesty | Close Phase 0 audit gaps before geographic integration | Desktop Chrome/Firefox/Safari and mobile checks recorded; source/date/fallback labels visible; Nominatim compliant configuration or search disabled; non-open imagery resolved; permit inputs fail closed with negative tests; empty/failed agent runs recover; all tests pass | Closed 2026-10-12 — 21 Node tests pass; Chrome 155 and Firefox 122 audits pass with no uncaught errors; Safari not tested (owner setting); see docs/PHASE_1_REPORT.md |
| 2A — San Francisco technical discovery | Audit, 3D stack, landmarks, data inventory, pilot corridor, agent/workspace and demo specs | Six Phase 2A documents with verified facts, assumptions, risks and open questions; no implementation; docs and tests pass | Completed 2026-10-13 — see docs/PHASE_2A_TECHNICAL_AUDIT.md |
| 2B — San Francisco world foundation | Earth → SF cinematic flight, SF navigation/search, procedural Golden Gate and landmarks, dated/hashed DataSF snapshots, Folsom/Howard pilot view with record inspection | Founder's 2B brief: globe functional; SF fly-to; buildings/streets/coast/terrain; recognizable Golden Gate; genuine sourced records inspectable; observed vs synthetic distinguished; existing tests pass; no paid service | Completed 2026-10-13 — see docs/PHASE_2B_REPORT.md |
| 2C — Real-world agents & coordination intelligence | Deterministic six-role agent pipeline on DataSF snapshots, scenario laboratory (S0–S4), coordination gateway, live/paused/replayed workspace synced with the map, guided demo | Founder's 2C brief: real records, reproducible findings, map responds, actual operations shown, multiple scenarios, metric provenance, gateway blocks unsupported proposals, human review mandatory, existing features intact, no paid service | Completed 2026-10-13 — see docs/PHASE_2C_REPORT.md |
| 2D — San Francisco city intelligence foundation | Domain/dataset registry, 6 new real datasets (trees, removal notices, building permits, energy benchmarks, parks, sidewalks), knowledge graph, simulation interface, 8-role cross-domain investigation, Decision Brief and fail-closed decision gateway, thematic UI and guided demo | Founder's Phase 2 brief: one evidence-grounded cross-domain discovery, ≥ 3 alternatives, adjustable recomputed parameter, adversarial review, human decision; ≥ 2 new real domains; existing features intact; no paid service | Completed 2026-10-13 — see docs/PHASE_2_REPORT.md |

| 5 — Generalization | Multiple regions and specialist simulators | Portable scenario/permit contracts and validated adapters; geographic/data-access boundaries tested | Planned |
| Later | Energy, water, subsurface, collaboration, XR | Separate scoped acceptance criteria and data/security review before implementation | Vision only |

Phase 1 is closed; its report lists the limits carried forward (headless-only coverage, Safari/iOS untested, synthetic traffic, no real signatures). Phases 2A–2D are complete. Phase 3 starts only on the founder's explicit request; recommendations (field-verification loop, environment/accessibility data, scheduled refresh, calibrated traffic once counts and timing exist, optional model provider) are in docs/PHASE_2_REPORT.md. Engine changes still require an explicit task authorizing them.

Long simulations run offline only on explicit request; provide reproducible commands instead of launching repeated searches. Existing browser action “Lancer les agents” runs the bounded demonstration (3,030 reported evaluations).
