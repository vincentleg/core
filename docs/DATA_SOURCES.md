The globe currently falls back to an 8 m display height where `render_height` is absent. The source panel now discloses the fallback and explicitly states observation dates are unknown. A map-backed building is not a validated engineering model. Map/font requests go directly from browsers to providers. Search text now stays local; no Nominatim or Esri requests are made.

Overpass, SUMO, observed traffic counts, EnergyPlus, underground network plans and LLM APIs are future possibilities only; none is integrated. Free/open tools and accessible data have separate licenses. CORE code is provisionally proprietary (FD05), with no open-source project grant; third-party licenses remain distinct. See IP_AND_ATTRIBUTION.md.

San Francisco candidate sources researched in Phase 2A are listed in [SF_DATA_INVENTORY.md](SF_DATA_INVENTORY.md); only the six DataSF datasets above are integrated. OSM-derived geometry embedded in `src/sf-world.js` (Transamerica footprint, tower positions) is © OpenStreetMap contributors under ODbL and attributed on screen. Hillshade (AWS Terrain Tiles) now loads by default from zoom 10.

Phase 2D multidomain datasets (street trees, tree removal notices, building permits, energy benchmarks, parks, sidewalk widths) and identified-but-not-integrated candidates are documented in [DATA_SOURCE_REGISTRY.md](DATA_SOURCE_REGISTRY.md); all are DataSF ODC-PDDL, bounded to the corridor, PII-scrubbed and checksummed in `data/sf/manifest.json`.

Phase 11 reuses the existing `data/sf9` snapshot only: Analysis Neighborhoods (`j2bu-swwd`), 2024 High Injury Network (`enwt-3u8m`), Traffic Crashes Resulting in Injury (`ubvf-ztfx`, aggregate counts only), and Street-Use Permits (`b6tj-gt35`). Each manifest entry identifies DataSF PDDL, provider, retrieval date, transformations and SHA-256. `scripts/science.mjs` publishes derived comparisons in `data/science/sf-traffic.json`; no new collection, proprietary source, personal contact data or service is introduced. Dossier links retain attribution. The uncalibrated index is not a forecast of accidents or traffic.

FD06 source qualification only: SFMTA count candidates are inventoried in [pilot/source-manifest.json](pilot/source-manifest.json). Access was checked, reuse rights remain UNVERIFIED, and no measured SFMTA count payload is redistributed or used for calibration.

## V9.6 local intelligence additions

- LangGraph.js **1.5.1**, official SQLite checkpointer **1.1.0** (MIT); exact transitive versions in `scripts/intelligence/package-lock.json`. One local worker, no LangSmith/cloud tracing. CrewAI and Microsoft Agent Framework were considered but add no benefit to this existing Node toolchain. Ollama is the existing inference runtime, not an orchestration framework. OSMnx is a geographic utility; the existing CORE walk-graph decoder avoids adding Python/geospatial dependencies.
- Existing authorized **qwen3:8b**, Q4_K_M, reused through loopback-only Ollama; Qwen3 Apache-2.0. No new model download or paid inference. Provider rejects nonlocal endpoints and redirects. Public site never calls a visitor's model.
- **U.S. Census Bureau** incorporated-place boundaries, January 1, 2026 vintage, retrieved directly from its [official service](https://tigerweb.geo.census.gov/arcgis/rest/services/TIGERweb/Places_CouSub_ConCity_SubMCD/MapServer/4). [Official technical documentation, §1.1–1.2](https://www2.census.gov/geo/pdfs/maps-data/data/tiger/tgrshp2024/TGRSHP2024_TechDoc.pdf) permits reproduction with source citation; statistical boundaries are not legal land descriptions. Simplified geometry, WGS84; no personal data. No Census endorsement implied.
- **OpenStreetMap contributors**, ODbL 1.0: 16 municipal pedestrian study windows, approximately 600 m wide, plus the previously validated SF graph. [Copyright and reuse terms](https://www.openstreetmap.org/copyright); [Overpass resource guidance](https://dev.overpass-api.de/overpass-doc/en/preface/commons.html). Two bounded requests: first exceeded the local response budget and was discarded; a smaller request succeeded. No ongoing crawling. Derived database `data/intelligence/walk-network.json` and OSM-derived region node indices are supplied under ODbL; preserve attribution and share-alike. Boundary polygons originate from Census. Building-interior samples at approximately 1 m reject crossing edges; mapped geometry is not field validation or a guarantee of pedestrian access.
- **DataSF SF Planning housing completions**: reuse the previously approved `xdht-4php` public-domain source and aggregate query only. Worker can refresh counts by neighborhood since 2015. No addresses, people or raw individual records. Housing completions are not traffic counts, housing need, affordability, severity or causal evidence for signal timing. Dates, source, units, hash and limitations travel with each tool output. No Oakland transport measurements or regionwide news feeds are integrated.

## V9.8 search and voice additions

- Reuse the authorized Census municipal reference points, DataSF Folsom/Howard geometry, OSM pedestrian positions and public agent/task records. Geographic assignments do not establish live workers or measurements outside coverage.
- **Photon/komoot official geocoding API**, [documented reasonable project usage](https://github.com/komoot/photon#demo-server), verified 2026-10-20; no guarantee of availability. Opt-in submitted queries only, five uncached requests/minute per session, no typeahead/crawl, bounded timeout/results and memory cache. [OpenStreetMap contributors, ODbL 1.0](https://www.openstreetmap.org/copyright): preserve attribution/share-alike for the small derived landmark cache in `data/intelligence/places.json`. Regenerate with `node scripts/intelligence-places.mjs`; retained named features, service query, retrieval time and response hashes document provenance. Reference points derive from returned OSM feature extents; they are approximate, not surveyed centroids. The cache explicitly uses Bay Bridge West Span, not a toll or office POI.
- **whisper.cpp v1.9.5**, official source commit `d1be6fde11ac6e0407606b4e42fe72d34add8037`, [MIT](https://github.com/ggml-org/whisper.cpp/blob/v1.9.5/LICENSE). Multilingual base comes from the [download location identified by the project](https://github.com/ggml-org/whisper.cpp/blob/v1.9.5/models/README.md), uses OpenAI Whisper's MIT weights, and matches the official SHA-1. Ignored local source/binary/model only; no model or raw microphone data is redistributed in the public bundle. CMake 3.31.6 is an isolated build tool, not a shipped application dependency.
- Browser speech synthesis uses installed local-service voices; no voice model is redistributed. Optional browser recognition requires explicit consent because browser vendors may process audio remotely; it is not presented as universally local. Default CORE capture/transcription retains no raw audio. No paid inference or speech provider, API key, subscription, tracker or billing configuration was introduced.
