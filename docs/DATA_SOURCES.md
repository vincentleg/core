# Data sources and dependencies

Inventory revisited at Phase 2B closure (2026-10-13). A reachable URL is not a license grant, uptime guarantee, proof of current data or production approval. No paid account, API key or billing was configured.

| Provider / component | Existing use | License / terms and limitations |
| --- | --- | --- |
| MapLibre GL JS 5.7.3 via unpkg | Globe renderer, pinned JS/CSS | BSD-3-Clause and bundled notices; [versioned license](https://github.com/maplibre/maplibre-gl-js/blob/v5.7.3/LICENSE.txt). Requires graphics/browser support. Upgraded from 5.6.0 to obtain upstream terrain/tile-retention crash fixes (D010). |
| NASA GIBS — Blue Marble shaded relief and bathymetry (Phase 7) | Opening Earth view only (WMTS `BlueMarble_ShadedRelief_Bathymetry`, Web Mercator, ≤ level 8), faded out on ENTER CORE; never evidence | NASA Earth science data are shared fully and openly without restriction on reuse; GIBS asks for an acknowledgement, shown on the landing and in the map attribution. | DataSF (`data.sf.gov`) — Streets (3psu-pn9h), Street Intersections (gmfx-8h6i), Street-Use Permits (b6tj-gt35), Large Utility Excavation Permits (i926-ujnc), Utility Excavation Moratorium Streets (5wbp-dwzt), SFMTA Temporary Street Closures (8x25-yybr) | **Integrated (Phase 2B)** as dated snapshots in `data/sf` (≈430 KB) for the Folsom/Howard pilot, via `scripts/sf-snapshot.mjs` | ODC Public Domain Dedication and License (PDDL), per the DataSF catalog. Administrative records: a permit is not proof of work; moratoria are current-only; closures cover SFMTA permits only. Personal contact columns removed; emails/phone numbers in free text redacted; permit holders kept only when clearly organisations. Manifest records URLs, retrieval time and SHA-256; the browser re-verifies checksums. Snapshot date 2026-10-13; refresh required before use. |
| NYC Open Data (`data.cityofnewyork.us`, Phase 10) — 2020 NTAs (9nt8-h7nd), VZV Priority Corridors (36nr-7fbp), Motor Vehicle Collisions – Crashes (h9gi-nx95, **aggregated counts only**), Street Closures due to Construction Activities by Block (i6b5-j7bu), Pedestrian Ramp Locations (ufzp-rrqu) | New York study area (Chinatown-Two Bridges, Lower East Side, East Village): `scripts/nyc-snapshot.mjs` → `data/nyc` (manifest with URLs, dates, SHA-256); public site reads the snapshot only, never the API | NYC Open Data Law (Local Law 11 of 2012, amended by Local Law 251 of 2017): public datasets without restriction on use; the City may require attribution of source, version and modifications. Summary verified by search; the codified text page refused access, so re-read it before any commercial use. Collisions: police-reported, no injury-severity class; CORE assigns them to the nearest corridor within 20 m and excludes limited-access roadways (FDR Drive, bridges, tunnels). Closures are authorisations, not permits or proof of execution. Ramp measurements date from 2017–2019. Not integrated: stormwater flood maps (file-only), geolocated permits, trees, costs |
| OpenStreetMap pedestrian network — New York (Phase 10) | `scripts/osm-walk.mjs --city new-york` → `data/osm/nyc-walk-network.json` (197 edges crossing one of 7,760 buildings removed; largest component) and `nyc-buildings-sample.json` (route-vs-building tests) | ODbL 1.0, © OpenStreetMap contributors; mapped geometry, not a field survey |
| Golden Gate Bridge Highway & Transportation District — design statistics | Published dimensions for the procedural bridge model | Public facts page; no asset copied. Model is CORE-generated geometry (approximate). |
| OpenStreetMap / OpenMapTiles | Streets, outlines, names, building footprints/heights | [OSM copyright](https://www.openstreetmap.org/copyright): ODbL and attribution/share-alike obligations where applicable. Retain OpenMapTiles attribution. Coverage, heights and freshness vary; no exact physical replica is implied. |
| Nominatim public endpoint | **Disabled**; pilot city / coordinate search is local | [Usage policy](https://operations.osmfoundation.org/policies/nominatim/): maximum 1 request/second across the application, identifying Referer/User-Agent, attribution, ability to switch provider, caching where possible; no confidential searches. Public endpoint calls were removed because aggregate rate control cannot be guaranteed by this static app. No geocoding compliance claim is made; re-enabling requires resolving service requirements. |
| Mapzen / AWS Terrain Tiles | Terrarium PNGs from `elevation-tiles-prod` for hillshade and exaggerated relief | [Registry](https://registry.opendata.aws/terrain-tiles/) points to [source-specific attribution](https://github.com/tilezen/joerd/blob/master/docs/attribution.md). Composite dataset: check underlying terms for the selected region; the source panel identifies regional providers and links full upstream credits; exact source obligations are not globally certified. Separate hillshade/terrain DEM sources remain; terrain switching passed the Phase 1 browser audits on MapLibre 5.7.3. Approximate terrain, not survey data. |
| Esri World Imagery | **Disabled/removed from map sources**; historical endpoint at `server.arcgisonline.com/.../World_Imagery/MapServer` | Proprietary/composite imagery, **not open data**. Existing service attribution mentions Esri, Maxar and Earthstar; exact source terms and attribution for each area are not cleared. [Service metadata](https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer). Replace/remove or explicitly resolve before production; do not add credentials or a paid subscription. |
| Google Fonts | Oxanium, IBM Plex Sans, IBM Plex Mono via external CSS | Font licenses must be retained if vendored; [font guidance](https://fonts.google.com/faq). Remote CSS/assets are not pinned and involve third-party requests; system-font fallbacks exist. |
| CORE synthetic fixtures | Five-intersection geometry, assumed signal plan, seeded demand, generated buildings, illustrative globe outlines | Created in repository; no observed traffic, calibration, live sensors or external roadwork records. Permit assumptions and corridor footer disclose synthesis. |

The globe currently falls back to an 8 m display height where `render_height` is absent. The source panel now discloses the fallback and explicitly states observation dates are unknown. A map-backed building is not a validated engineering model. Map/font requests go directly from browsers to providers. Search text now stays local; no Nominatim or Esri requests are made.

Overpass, SUMO, observed traffic counts, EnergyPlus, underground network plans and LLM APIs are future possibilities only; none is integrated. Free/open tools and accessible data have separate licenses. CORE repository licensing remains undecided.

San Francisco candidate sources researched in Phase 2A are listed in [SF_DATA_INVENTORY.md](SF_DATA_INVENTORY.md); only the six DataSF datasets above are integrated. OSM-derived geometry embedded in `src/sf-world.js` (Transamerica footprint, tower positions) is © OpenStreetMap contributors under ODbL and attributed on screen. Hillshade (AWS Terrain Tiles) now loads by default from zoom 10.

Phase 2D multidomain datasets (street trees, tree removal notices, building permits, energy benchmarks, parks, sidewalk widths) and identified-but-not-integrated candidates are documented in [DATA_SOURCE_REGISTRY.md](DATA_SOURCE_REGISTRY.md); all are DataSF ODC-PDDL, bounded to the corridor, PII-scrubbed and checksummed in `data/sf/manifest.json`.
