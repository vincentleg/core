# R2 — Visual multi-agent command centre (founder review, 2026-10-23)

Branch `foundation/civilization-reset`, built on R1 `c55d34e`. Scope: roadmap phase R2 in `docs/CIVILIZATION_FOUNDATION_2_0.md`. Uses the existing globe, Hybrid View, agent layers and panels; no new renderer, dependency, service, data source or agent execution. Not pushed or deployed.

## Authoritative agent count

`data/agents/sf-civilization.json` (generated by `scripts/agents-civilization.mjs`) lists **510 registered identities**: **501** with `city: san-francisco` and **9** coordinators without a San Francisco assignment (1 global coordinator, 1 assembly, 5 councils, 2 regional directors). Both earlier figures were true for different scopes. The tour now states both ("all 510 registered agents: 501 assigned to San Francisco and 9 …"), and `test/agent-records.test.js` ties the copy to the registry. The urban map draws **500** of the San Francisco identities: all except the single city-level direction (`scripts/urban-build.mjs`). Its chip shows how many are currently drawn while the layer loads in steps of 50.

These are registered identities, not 510 working agents. Execution modes in the registry: 19 run deterministic tools, 7 are model-assisted (need a local model), 35 are coordination-only, 13 are planned/unavailable, and 436 are identities animated by the deterministic CORE engine. **35** identities have any recorded work in the published files below.

## What was added

- `src/earth/agent-records.mjs`: a pure index joining the registry with the only published activity records, plus HTML builders. Every agent panel (urban and civilisation) now ends with **Records and status sources**: agent class, geographic scope (city, sector, virtual post), recorded missions, last recorded activity with its file, tool executions and rejections, evidence references with their recorded provenance, human supervision (permission, software supervisor, pending human review), the viewer's related private contributions (counted in their own browser only), and **Where each status comes from**. Missing fields read "Not recorded" / "No … recorded".
- Location inspector: in CORE World or Hybrid View, a click on an empty place (zoom ≥ 11) lists registered agents whose virtual post lies within 500 m, nearest first, with class and whether recorded work exists; each opens its dossier. Keyboard path: the view explainer (`?`) offers **Agents near the map centre**. Real Earth clicks are unchanged.
- My CORE: a contribution on `mission.sf.mobility` created after the recorded investigation shows **Related recorded investigation**: same mission, completed earlier by 7 agents, "the agents did not analyse your text". No other relation is inferred.
- Layout: the floating language selector no longer covers an open panel or list. On phones it sits beside the Real/CORE/Hybrid switch; on desktop the panel stops above it. The city status chip no longer covers the view switch on phones.
- Translations: the i18n catalog was regenerated and all 178 missing strings (R1, R2 and drift from earlier phases) were added in Spanish, German, Simplified Chinese and Portuguese. These are model-written drafts, as recorded in `src/i18n/i18n.mjs`, and the locale files keep their exact layout. The two tour count strings were also added, though the tour's `P()` strings are otherwise outside the catalog.

## Source of every displayed status

| Displayed | Source | Nature |
|---|---|---|
| Urban map state `working` / `queued` / `unavailable` | browser scenario worker in this page, only when the visitor runs the model | real local computation on assumptions |
| Urban map state `completed` | a completed task in `data/intelligence/work.json` (recorded 2026-10-19) or `data/urban/latest.json` (2026-10-18) | recorded |
| Urban map state `idle` | no recorded or running task | absence |
| Civilisation map state (working, meeting, travelling …) | `src/civilization/runtime.mjs` replay on a clock that runs only while a CORE page is open | browser replay, labelled "not live telemetry" |
| Registry status (registered, available …) | `data/agents/sf-civilization.json` | capability, not activity |
| Recorded missions, tools, findings, human review | `data/intelligence/work.json`, `data/urban/latest.json`, `data/civ/index.json` (2026-10-14) | recorded |
| Movement of figures | visualisation | not evidence of computation |

## Verification (new results, this phase)

- Unit: `test/agent-records.test.js` **8/8** (counts against the registry, record joins against the real files, missing-data labels, escaping, location search, contribution relation rules, privacy and execution boundaries, module syntax, CSS). Affected suites 102/102 before final CSS changes; full gate below.
- Browser `scripts/r2-agents-browser.mjs` **25/25**, twice (Chrome 155 headless, desktop 1440×1000 and mobile 390×844). It covers a real map click on an agent symbol, the dossier of an agent with recorded work, missing-data labels on an agent without records, the location inspector by click and by keyboard, Real Earth unchanged, the My CORE relation, selector/panel/attribution/switch/chip overlaps, no horizontal overflow, no network writes and no private files. Regressions: SF journey **22/22**, R1 lifecycle **21/21** (twice).
- Evidence (ignored by Git): `.core-local/evidence/r2-agents/`, `r2-r1-regression/`, `r2-sf-regression/`.

**Local test-server finding.** With `python3 -m http.server` (listen backlog 5), "Explore the Demo" failed to open in about half of runs, on the R1 build `c55d34e` (3/5) as on R2 (1/3). Loopback connections were reset during module loading, so an import failed. With the same server class and a 128-connection backlog, 5/5 runs passed, and all results above use it. A failed module load currently leaves no message to the visitor; that is a pre-existing robustness gap.

## Limitations

- Status is recorded or replayed, never live: CORE has no live agent telemetry.
- Only 35 of 510 identities have published recorded work; most dossiers correctly show "not recorded".
- On loopback hosts only, the existing `src/civilization/client.mjs` probes `.core-local/civ/state.json` (404 in the public build; disabled on public hosts). R2 reads no private file.
- Guided-tour strings (`src/earth/demo.mjs`, `P()` helper) are outside the i18n catalog and remain English in es/de/zh-CN/pt apart from the two count strings. Translations are unreviewed model drafts.
- Location search uses registry virtual posts, not real offices; New York missions are recorded without a loaded registry.
- Not tested: Safari/WebKit, Firefox, physical devices, screen readers.
