## Mission lifecycle (implemented)

| Stage | Who | What |
| --- | --- | --- |
| DISCOVERED | CORE executive (`CORE-CMD-0001`) | `discoverAll()` scans every workflow × neighbourhood. Only real signals become problems, in a priority queue (declared rule: severity × 2 + signal) |
| TRIAGED | Executive → city coordinator (`CORE-CTY-0002`) | Ownership is assigned to the workflow's department lead |
| ASSIGNED | Department lead | Plans bounded subtasks from the workflow's first tools plus every executable specialist whose department serves the workflow domains. **Approved procedures** from memory are applied here |
| INVESTIGATING | Specialists | Tools run with permission, scope and precondition checks, a time budget and bounded retries. A specialist can trigger a dependent request through another lead. The data verifier challenges freshness |
| CROSS_DOMAIN_REVIEW | Lead | Joins the results across domains; failures become coverage gaps sent to the reviewer; drafts a recommendation (labelled hypothesis) |
| EVIDENCE_VALIDATION | Adversarial reviewer (`CORE-SAF-0044`) | Every reference must resolve; modelled data must say so; recommendations may not use causal or decision language. Optional model interpretation, validated deterministically |
| PROPOSED_DECISION | Gateway (`CORE-SAF-0068`) | Proposal to human review; `authorizes: rien` |
| HUMAN_REVIEW → APPROVED / REJECTED / NEEDS_MORE_EVIDENCE | `human:<name>` only | Through `civ.mjs decide` or the control centre |

**Limits:**
- at most 14 subtasks per mission;
- delegation depth at most 2;
- 8 s per subtask and 2 attempts;
- 3 concurrent subtasks;
- at most 2 model calls per mission;
- at most 4 concurrent missions (2 used and measured);
- duplicate subtasks refused;
- emergency stop through the STOP file shared with the Phase 8 supervisor.

**Recovery:** a checkpoint is written after every stage. A restarted engine resumes from the last checkpoint, and a finished mission is never re-run.

## Learning (bounded)

| Mechanism | Source | Promotion | Effect |
| --- | --- | --- | --- |
| Procedures (leads) | Recorded failures: out-of-scope tool, unmet precondition | candidate → verified (verifier) → reviewed (reviewer ≠ author) → approved (rule: deterministic records) | The lead skips or does not delegate the tool. **Measured: 3 → 0 failures, 7 → 4 tool calls, same 15 findings** |
| Lessons (model interpreters, shared) | Validator rejections, quoting the rejected pattern | Same chain | Added to the system prompt. Measured effect is **not significant** (see the report) |
| World findings | Accepted cross-domain findings | Verified and reviewed by agents; **approved only by a human** decision on the mission | — |

Nothing in learning changes permissions, policies, code or model weights.

## Movement rules

1. **Valid ground positions only.** Agents stand at posts (distinct walkway nodes in their virtual zone) or at walkway nodes nearest a cited evidence location.
2. **Validated network.** Routes use only the OSM pedestrian network: sidewalks, crossings, footways. Any edge crossing a building footprint is removed (320 removed); only the largest connected component is kept. Routes have no off-network straight legs.
3. **Movement needs a reason:** recorded mission replay, recorded activity replay, or live local execution. No random wandering.
4. **Disclosure.** Trip speed is accelerated with the factor stated on each agent. Positions are never presented as physical inspections.
5. **Occlusion.** Agents behind 3D buildings, computed from the camera ray against building prisms, are faded.

## Deployment

**Public site:** `main` → GitHub Pages (static), https://vincentleg.github.io/core/

| Item | State |
| --- | --- |
| Third-party code | **None**: MapLibre 5.7.3 is vendored in `assets/vendor/` with SRI (hash identical to the previously pinned unpkg file) and its licence; fonts are self-hosted |
| CSP | `script-src 'self'` plus one hash; no CDN |
| Data published | Recordings only. No model endpoint is ever contacted; `.core-local/` is git-ignored and never deployed |
| Control centre | `control.html` is deployed but **inert** without the local server and its token. It is `noindex` and says so |

**Data refresh:** `.github/workflows/city-feed.yml` runs every 3 h, plus an hourly retry (Phase 9). A **freshness gate** makes scheduled runs collect only when the published data is at least 150 min old; manual runs always collect. Commit messages state the real trigger (`${GITHUB_EVENT_NAME}`). GitHub's best-effort scheduling means strict 3-hourly refresh is not promised.

**Local:**

| Command | Purpose |
| --- | --- |
| `node scripts/civ.mjs run --model --record` | Run missions with the model and publish recordings |
| `node scripts/control-server.mjs` | Open the URL with `#token=…` it prints |
| `node scripts/civ.mjs stop` / `resume --reviewer human:<name>` | Emergency stop and resume |

Publishing a recording still means a human commit, which the hooks check.
