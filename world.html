Entrez dans la Terre de CORE

Les agents de CORE travaillent dans le monde holographique. Autour de vous, la réalité apparaît : bâtiments, rues, trottoirs et arbres proches prennent leur aspect matériel.

Prototype local : un lieu (Folsom Street, San Francisco), un agent réel du registre CORE, un problème réel enregistré. Rien n’est transmis ni publié.
